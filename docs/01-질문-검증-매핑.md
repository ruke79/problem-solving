## B. 이론 전용 — 검증 케이스를 만들지 않은 질문

코드로 참/거짓이 갈리지 않는 질문들이다. 억지로 케이스를 만들면 "검증한 척"이 되므로 만들지 않았다.

| Q36 API 게이트웨이 역할 | 아키텍처 책임 배분 |
