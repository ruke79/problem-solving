# docs/10 적용 내역 — Part 1~11 원고에 반영한 것

`docs/10-원고-수정-지시서.md` 의 적용 순서(A→C→B→D)대로 Part 1~11 원고에 직접 반영했다.

## 만드는 방법이 달랐던 두 그룹

- **Part 1·2·7·8·9·10·11** — 원본이 markdown 이라 그 파일을 그대로 편집했다. 100% 원본 그대로다.
- **Part 3·4·5·6** — 원본이 PDF 라 PDF 자체는 편집할 수 없다. PDF 에서 추출한 텍스트로
  markdown 을 다시 만들고 그 위에 수정을 반영했다. **문장·순서·내용은 원문과 동일하지만,
  PDF 줄바꿈 지점에서 원래 띄어쓰기가 있었는지는 텍스트 추출 단계에서 알 수 없어 소실된다.**
  그래서 단어 중간에 어색한 공백이 남아 있을 수 있다(예: "빌린 시점" 처럼 원래 붙어야 할 곳이
  "빌린 시 점" 으로 보일 수 있음). 억지로 자동 교정하면 반대로 필요한 공백을 지워버리는 사고가
  나서(직접 겪었다) 손대지 않고 남겨 뒀다. 발화 전에 한 번 훑어보시는 걸 권한다. 각 파일 위쪽에
  이 사실을 알리는 안내문을 넣어 뒀다.
