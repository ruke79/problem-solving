# 면접 답변 원고 (Q1~Q200)

이 디렉터리는 검증 랩(`verify-labs`)이 대조한 **원고 자체**를 보관한다.
지금까지는 원고가 저장소 밖에 있어서 랩이 지적만 하고 적용은 할 수 없었는데,
2026-08-13 에 저장소로 들여왔다.

## 세 벌이 있다

|  | `원본/` | `수정본/` | `회화체/` |
|---|---|---|---|
| **무엇인가** | 받은 그대로. 아무것도 고치지 않았다 | 원본 + `docs/10-원고-수정-지시서.md` 의 지적 8건·보강 9건 반영 | 수정본을 **말투만** 회화체로 다시 쓴 것 |
| **범위** | Part 1·2·7~11 (`.md`)<br>Part 3~6 은 PDF 추출 `.txt` | **Part 1~11 · Q1~Q200 전부** (`.md`) | **Part 1~11 · Q1~Q200 전부** (`.md`) |
| **사실관계** | 지적 반영 **전** | ✅ **기준으로 삼을 것** | 수정본과 **동일** (숫자·주장·구조 그대로) |
| **문체** | 문어체 | 문어체 (원본 유지) | 회화체 |
| **굵은 글씨** | 원본 그대로 | 지적 ⑤ 로 Part 7~10 정리<br>(예: Part10 400→74) | 수정본을 따름 |
| **언제 쓰나** | 무엇이 바뀌었는지 대조할 때 | 내용을 확인하거나 인용할 때 | 실제로 소리 내어 연습할 때 |
| **일본어 / 한국어** | 양쪽 | 양쪽 | 양쪽 |

### 수정본 → 회화체 에서 바뀐 것 / 바뀌지 않은 것

| 바뀐 것 (말투) | 바뀌지 않은 것 (내용) |
|---|---|
| 한 문장을 짧게 끊음 — 문어체 한 문장이 두세 문장이 됨 | 기술적 주장과 결론 |
| "~하며", "~로써", "~인 반면" → "그리고", "그래서", "대신에" | 모든 수치와 측정값 |
| 한자어를 입에 붙는 말로 (담보한다 → 보장한다) | Q번호 상호 참조 (→ Q54, Q100 …) |
| 실제로 말할 때 쉬는 지점에서 문단을 나눔 | 재출제 표시와 ⚠️ 주석 |
| — | 정중함 (**~습니다** / **です・ます**). 면접이니까 |

전체 방침은 `회화체/Part1.md` 머리말에 적어 두었다.

**예외 한 건** — `회화체/Part11.md` 의 Q170~190 은 굵은 글씨를 그대로 남겼다.
원고 저자가 "굵은 부분이 다른 지원자와 차이를 만드는 지점"이라고 명시한 의도적 강조라서,
지적 ⑤ 의 대상이 아니었고 회화체에서도 건드리지 않았다.

## 원본에 대한 고지

- **Part 1·2·7·8·9·10·11** — markdown 으로 받았다. `원본/PartN.md` 가 받은 파일 그대로다.
- **Part 3·4·5·6** — PDF 로 받았다. PDF 는 저장소에 넣지 않고, 텍스트 추출 결과를
  `원본/PDF-추출-Part3-6/` 에 두었다. **PDF 줄바꿈 지점의 띄어쓰기는 추출 단계에서
  소실된다** — 그래서 이 네 파트의 `수정본/` 에는 단어 중간에 어색한 공백이 남아 있을 수 있다.
  자동 교정을 시도했다가 오히려 필요한 공백을 지우는 사고가 나서 되돌렸고, 대신 각 파일
  머리말에 고지를 넣어 두었다.

## 무엇이 고쳐졌나

`수정본/00-적용-내역.md` 에 A(사실 오류)·B(실물 미재현)·C(표현)·D(보강) 별로 정리돼 있다.
지적의 근거가 된 검증 케이스는 `docs/10-원고-수정-지시서.md` 에서 찾을 수 있고,
각 케이스는 `./gradlew test` 로 다시 돌려 숫자를 직접 확인할 수 있다.

## 일본어 동사 전수 조사 (2026-08-31)

`수정본/` 의 일본어 답변에서 **동사 539종(총 5,995회)** 과 **한자어+する 425종** 을 형태소
분석기로 전수 추출해 검토하고, **11곳을 고쳤다**(`회화체/` 에도 10곳 반영 — 나머지 1곳은
회화체가 이미 맞게 되어 있었다). 상세와 근거는 [`docs/12-일본어-동사-전수-조사.md`](../docs/12-일본어-동사-전수-조사.md).

- **확정 오류 1건** — `リタイア`(은퇴) → `リトライ`(재시도). **`원본/` 에도 있는 원고 유래 오류**다.
- **연어 불일치 6건** — `リクエストが襲う` → `押し寄せる` 등.
- **격식 4건** — `即死` → `即座にダウン`, `時間を溶かす` → `時間を費やす` 등.
- **일부러 두지 않은 것이 더 많다** — `全件を舐める`·`Redisを噛ませる`·`ノードが死ぬ` 등은
  실제로 일본 엔지니어가 쓰는 말이라 과잉 교정하지 않았다.

> **이 조사는 실행으로 판정할 수 없다.** 추출은 기계적이고 재현 가능하지만
> **자연스러움 판정은 의견이며, 원어민 검수를 대체하지 않는다**(`docs/12` §0).
> 이 랩의 `CONFIRMED` 와 같은 수준의 근거로 취급하면 안 된다.
