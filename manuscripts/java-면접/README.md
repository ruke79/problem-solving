저쪽이 아키텍처·데이터·조직까지 넓게 다루는 반면, 이쪽은 **Java 언어와 런타임에 집중**한다.

- **"반드시 나올 만한 것"만 골랐다.** 개수를 채우려고 넣은 문항은 없다.

> 근거를 못 대면 오히려 마이너스가 됩니다.

## 일본어 품질에 대한 고지

`docs/12-일본어-동사-전수-조사.md` 에서 만든 검사를 **이 원고에도 그대로 돌렸습니다.**

```
문말 체    敬体 537 / 常体 2(열거의 체언止め)  → です・ます체로 통일됨
동사       253종 · 1,296회
조사       を + に격 동사 오용  0건
재발 검사  1부에서 고친 표현(リタイア·襲う·即死 등) 0건
```

다만 **§0 의 고지가 여기에도 그대로 걸립니다** — 추출은 기계적이지만 **자연스러움 판정은
의견이며, 원어민 검수를 대체하지 않습니다.** 특히 **は/が 의 선택은 검사하지 못했습니다.**

답할 수 있는 범위가 달라집니다.**

## 한국어 품질에 대한 고지 (2026-09-02)

일본어를 먼저 쓰고 한국어를 붙이는 작성 순서 탓에, 한국어 쪽에 **일본어 축자 번역이
섞여 있었습니다.** 사용자가 Q73 의 "간이 배압(簡易的な背圧)"을 지적해 준 것을 계기로
🇰🇷 답변 145개 전량을 통독 + 패턴 검사로 훑어 다음을 고쳤습니다.

```
일본어 잔존      1건  — Q86 「切り分け」가 한국어 문장에 그대로 남아 있었다
축자 번역 표현   14건 — 간이 배압(Q73), 탁상 계산(Q71), 솔직하게 쓰다(素直に·Q105/Q124),
                       ~측(Q18/Q73), 상정되어 있지 않다(Q125), 이관(移行·Q145),
                       전건(Q120), ~라고 이해하고 있습니다(Q15/Q21) 등
검사             한국어 답변 안의 가나·한자 잔존 0건 확인 (기계 검사)
```

패턴 검사만으로는 못 잡습니다 — "간이" 패턴은 11건 중 10건이 "시**간이**" 오탐이었습니다
(`docs/12` §0 과 같은 교훈). 그래서 전량 통독을 병행했지만, **자연스러움 판정은 의견**이며
한국어 원어민 재검토를 대체하지 않습니다.
