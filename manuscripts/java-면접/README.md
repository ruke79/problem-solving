# Java 면접 답변 스크립트 — Q1~Q145

기존 `manuscripts/` 의 시니어 면접 원고(Q1~Q200)와 **별개의 세트**다.
저쪽이 아키텍처·데이터·조직까지 넓게 다루는 반면, 이쪽은 **Java 언어와 런타임에 집중**한다.

- **일본어 답변 + 한국어 답변** 양쪽. 형식은 기존 원고와 같다(`🇯🇵 回答` / `🇰🇷 답변`).
- **답변은 짧다.** 한 문항 **30~40초** 분량 — 먼저 결론을 말하고, 더 물으면 그때 들어가는 구성이다.
- **"반드시 나올 만한 것"만 골랐다.** 개수를 채우려고 넣은 문항은 없다.

## 이 세트의 성격 — 답변의 근거

기존 원고와 달리, 이 145문항 중 **일부는 이 저장소 안에 실행 근거가 있습니다.**

| 문항 | 근거 |
|---|---|
| Q104 JIT 워밍업 | `PERF-04` — 워밍업 전후 실측 |
| Q106 마이크로벤치마크 | `PERF-04`·`docs/02` §1-2 (해상도와 최소 여유) |
| Q115 예외 비용 | `PERF-12B` — 깊은 스택에서 3배 이상 |
| Q120 스트림 지연 평가 | `PERF-12C` — 시간이 아니라 **람다 호출 횟수**로 확인 |
| Q130 버퍼드 I/O | `PERF-12A` — 하부 `read` 호출 524,288 → 65회 |
| Q113 압축 oop 32GB | **검증하지 못했다** — 32GB 힙을 띄울 수 없다(`docs/02` §9-1) |
| Q92·Q93 G1 · 거대 객체 | **검증하지 못했다** — 별도 JVM 이 필요하다(`docs/02` §9-3) |

> **마지막 두 줄이 중요합니다.** 이 원고에는 **실행으로 확인한 것과 책·문서에서 읽은 것이
> 섞여 있습니다.** 면접에서 수치를 인용할 때는 "제 환경에서 재 봤을 때는" 처럼
> **직접 측정한 것인지 아닌지를 구분해 말하는 편이 안전합니다.** 되물었을 때
> 근거를 못 대면 오히려 마이너스가 됩니다.

## 일본어 품질에 대한 고지

`docs/12-일본어-동사-전수-조사.md` 에서 만든 검사를 **이 원고에도 그대로 돌렸습니다.**

```
문말 체    敬体 537 / 常体 2(열거의 체언止め)  → です・ます체로 통일됨
동사       253종 · 1,296회
조사       を + に격 동사 오용  0건
재발 검사  1부에서 고친 표현(リタイア·襲う·即死 등) 0건
```

다만 **§0 의 고지가 여기에도 그대로 걸립니다** — 추출은 기계적이지만 **자연스러움 판정은
의견이며, 원어민 검수를 대체하지 않습니다.** 특히 **は/が 의 선택은 검사하지 못했습니다.**
