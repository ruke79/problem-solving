## 이 세트의 성격 — 답변의 근거

**이 저장소에는 파이썬 실행 검증 모듈이 없다.** `verify-labs` 계열은 전부 JVM 기반이라,
이 50문항은 **문서·공식 문서·실무 경험에 근거한 서술**이다. Java·Spring 세트처럼
`PERF-*`·`SPRING-*` 같은 케이스 id 를 붙일 수 있는 문항이 없다.

> **그래서 수치를 말하지 않았다.** "몇 배 빠르다" 같은 숫자는 이 세트에 거의 없고,
> 대신 **왜 그런 성질을 갖는지**로 답하게 썼다. 면접에서 수치를 인용해야 한다면
> 그 자리에서 재 본 것인지 읽은 것인지 밝히는 편이 안전하다
> (`docs/00` §8 의 정직성 원칙을 이 세트에도 그대로 적용했다).

파이썬 쪽에 같은 수준의 실행 근거를 붙이려면 별도 모듈(pytest 기반 검증 하네스)이 필요하다 —
지금은 **없다는 사실을 적어 두는 것**까지가 이 문서의 범위다.
