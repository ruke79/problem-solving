GIL とは何で、何が制限されますか？
GIL 이란
PYTHON Q14빈출
CPython のインタプリタが同時に一つのスレッドしか Python バイトコードを実行させない仕組みです。制限されるのは CPU バウンドの並列化で、I/O 待ちの間は GIL が解放されるので、ネットワークやファイル待ちが多い処理はスレッドでも効果があります。

スレッド・プロセス・asyncio はどう使い分けますか？
스레드·프로세스·asyncio 사용 구분
PYTHON Q15빈출
判断の起点は「待っているのか、計算しているのか」です。I/O バウンドで接続数が多いなら asyncio、既存のブロッキングライブラリを使うならスレッド、CPU バウンドなら multiprocessing でプロセスに分けます。

PYTHON Q2함정
デフォルト引数にリストを指定すると何が起きますか？
기본 인자에 리스트를 지정하면 생기는 문제
PYTHON Q2함정
デフォルト値は関数の定義時に一度だけ評価されるので、呼び出しをまたいで同じオブジェクトが使い回されます。対策は None を既定にして、関数の中で if x is None: x = [] とすることです。
PYTHON Q3함정
浅いコピーと深いコピーの違いは？
얕은 복사와 깊은 복사의 차이
PYTHON Q3함정
浅いコピーは一段目だけを新しく作り、中の要素は元と同じオブジェクトを参照します。ネストした構造を浅くコピーすると内側の変更が元にも及ぶので、必要なときだけ copy.deepcopy を使い、そもそも不変にする設計を優先します。
PYTHON Q26빈출
CPython のメモリ管理はどうなっていますか？
CPython 의 메모리 관리
PYTHON Q26빈출
基本は参照カウントで、参照が 0 になった瞬間に解放されます。ただし循環参照は参照カウントでは消えないので、世代別のガベージコレクタが補います。

제너레이터의 장점
PYTHON Q8
