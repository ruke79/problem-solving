# Spring Boot 면접 답변 스크립트 — Q1~Q145

`manuscripts/java-면접/` 의 자매 세트다. 저쪽이 **Java 언어와 런타임**이라면, 이쪽은
**Spring Boot 프레임워크와 그 위의 실무**를 다룬다.

- **일본어 답변 + 한국어 답변** 양쪽. 형식은 기존 원고와 같다(`🇯🇵 回答` / `🇰🇷 답변`).
- **답변은 짧다.** 한 문항 **30~40초** 분량.
- **"반드시 나올 만한 것"만 골랐다.** 개수를 채우려고 넣은 문항은 없다.
