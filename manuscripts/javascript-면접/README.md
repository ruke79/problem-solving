- 문체는 다른 세트와 같은 **です・ます체**.

## 이 세트의 성격 — 답변의 근거

**이 저장소에는 자바스크립트 실행 검증 모듈이 없다.** `verify-labs` 계열은 전부 JVM 기반이라,
이 50문항은 **사양·MDN·실무 경험에 근거한 서술**이고 `PERF-*` 같은 케이스 id 를 붙일 수 있는 문항이 없다.

> 그래서 **수치를 말하지 않았다.** "몇 배 빠르다" 대신 "왜 그런 성질인가"로 답하게 썼다.
> 면접에서 숫자를 인용해야 한다면 그 자리에서 잰 것인지 읽은 것인지 밝히는 편이 안전하다
> (`docs/00` §8 의 정직성 원칙).

다만 **브라우저 보안 문항(Q25 XSS · Q31 CSRF · Q30 CORS)은 서버 쪽 대응 케이스가 이 저장소에 있다** —
`SEC-01`(CSRF)·`SEC-02`(XSS)·`SEC-03`(CORS 프리플라이트). 같은 주제를 서버에서 실행으로 확인한 것이라,
면접에서 "프런트에서는 이렇게, 서버에서는 이렇게 막습니다"로 이어 말할 수 있다.
