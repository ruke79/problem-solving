## 정직한 고지

- **전 장을 통독했다**(1~15장, 부록 A·B). 원문은 PDF 추출 텍스트라 표·코드 일부가 흐트러졌고, 그림은 캡션으로만 읽었다.
- ✅ 는 이 환경(JDK 17.0.19 / 21.0.10 / 25.0.4, Linux 4코어)에서 실행한 것, 📄 는 문서로만 아는 것이다. 장별 요약의 §4 표에 하나씩 표시했다.
- 클러스터가 없어 8·9·14장의 K8s·Argo·Kafka 스트림 명제는 실행하지 않았다. `verify-labs-kafka` 의 브로커 7건은 이 책과 무관하게 먼저 있던 것이다.
- 2판이 인용한 수치(이미지 크기·벤치마크)는 그대로 옮기되 재측정하지 않았다 — §4 에 "미검증" 으로 남겼다.
