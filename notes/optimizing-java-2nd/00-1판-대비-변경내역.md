# 1판(2018) → 2판(2024) 변경 내역

> *Optimizing Java*(2018, JDK 8/9 기준) 와 *Optimizing Cloud Native Java*(2024, JDK 21 기준) 를 **장 단위로 대조**한 문서.
> 근거 표기 — ✅ 두 판의 원문에서 목차·키워드 빈도로 확인 · 📄 통독 인상. 장별 세부는 각 요약 파일의 §3 에 있다.

## 3. 장별 변경 요지

각 항목의 상세는 링크된 요약의 §3 에 있다.

- **1장** — 파이프 비유 확장(용량=저수지·좁은 입구, 저하=풍선), 그림 도구 Censum → JMC, 「클라우드 시스템의 성능」 신설(운영자의 아홉 질문, 배포 단위 컨테이너, CapEx→OpEx). → [`01`](01-최적화와-성능의-정의.md)
- **2장(← 1판 4장)** — 테스트 유형·인지 편향은 그대로. 통계 절이 5장에서 옮겨 오고 **Georges et al. 2007** 인용 추가. **엘스버그의 역설 삭제.** 안티패턴 목록은 부록 B 로. → [`02`](02-성능-테스트-방법론.md) · [`B`](B-성능-안티패턴-카탈로그.md)
- **3장(← 1판 2장)** — 확장 로더 → 플랫폼 로더, `rt.jar` → 모듈 이미지, JVM 목록(Temurin·Corretto·GraalVM·OpenJ9), 라이선스(NFTC), VisualVM → JFR/JMC. Nashorn 언급 삭제. → [`03`](03-JVM-개요.md)
- **4장(← 1판 6장)** — 이론은 그대로. **컨테이너 에르고노믹스**(CPU 1개 → Serial, 메모리 25%) 추가. → [`04`](04-GC-이해.md)
- **5장(← 1판 7장)** — **CMS 절 삭제**(1판 65회 → 2판 17회, 전부 과거형), **세대형 ZGC 신설**(39회), Shenandoah 갱신, C4/Zing·IBM J9 Balanced 절 삭제. → [`05`](05-고급-GC.md)
- **6장(← 1판 9+10장)** — 바이트코드·인터프리터·JIT·인라이닝·탈출 분석을 한 장으로. JITWatch(1판 30회) 축소. CDS·AOT 절 추가. → [`06`](06-JVM-코드-실행.md)
- **7장(← 1판 3장)** — 위치만 이동. 2024년 하드웨어 수치, 가상 스레드 노트, Agrona 참조·커널 우회 I/O 삭제. → [`07`](07-하드웨어와-OS.md)
- **8장(신규)** — MicroProfile 6.1·CNCF, 하이퍼바이저·컨테이너·네임스페이스·cgroups, OCI 이미지·멀티스테이지·Jib, 이미지 크기, north-south/east-west, 자바의 관심사(70% 컨테이너·절반 1 CPU·cgroups v2·1 GB → 256 MB). → [`08`](08-클라우드-스택-구성요소.md)
- **9장(신규)** — Compose·Tilt, K8s 두 평면·Deployment/Pod/Service, 사이드카·Istio, liveness/readiness(자바 워밍업), `:latest` 경고, 어피니티·보안, Telepresence, 블루/그린·Argo 카나리, 여섯 R, 기능 플래그, Knight Capital. → [`09`](09-클라우드-배포.md)
- **10장(신규, 1판 8장 일부 계승)** — 모니터링 vs 관측가능성, 세 기둥, **백분위수 재집계 불가**, 카디널리티, OpenTelemetry 표준. → [`10`](10-관측가능성-입문.md)
- **11장(신규)** — Micrometer 메트릭 파사드, OTel 자바 에이전트, 구조적 로그·상관 ID, MeterFilter, Spring/MicroProfile 통합. → [`11`](11-자바-관측가능성-구현.md)
- **12장(← 1판 13장)** — 세이프포인트 편향은 그대로. JFR 오픈소스 전제, **Async Profiler 중심**, 컨테이너 안 프로파일링(사이드카·이미지에 도구 없음), hprof·Illuminate·Thermostat·Honest Profiler 삭제. → [`12`](12-프로파일링.md)
- **13장(← 1판 12장 + 11장 메서드 핸들)** — JMM·락·`java.util.concurrent` 는 그대로. **가상 스레드**(23회)·고정·`ThreadLocal` 주의 추가. 1판 11장의 메서드 핸들 절이 여기로. → [`13`](13-동시성-성능-기법.md)
- **14장(신규)** — 분산 시스템: Kafka(62회) 프로듀서/컨슈머 튜닝, 백프레셔, 회로 차단기·재시도·멱등성, Pekko(5회). **1판 14장(Agrona·SBE·Aeron)과 무관.** → [`14`](14-분산-시스템-기법과-패턴.md) · 1판 [`14`](../optimizing-java/14-고성능-로깅과-메시징.md)
- **15장** — 1판(분할 코드 캐시·Compact Strings·Graal·Valhalla R/Q/U·Loom 예고) → 2판(구조적 동시성·ScopedValue·Panama FFM·Leyden 컨덴서/premain·Valhalla `value`). 2판 스스로 **"1판의 Valhalla 설명은 이제 완전히 틀렸다"** 고 적었다. → [`15`](15-현대-성능과-미래.md) · 1판 [`15`](../optimizing-java/15-Java-9-와-미래.md)
- **부록 A(← 1판 5장)** — JMH 사용법·죽은 코드 제거·Blackhole·상수 접기. 통계는 2장으로. → [`A`](A-마이크로벤치마킹.md)
- **부록 B(← 1판 4장 후반)** — 안티패턴 12개 + 인지 편향. 거의 그대로. → [`B`](B-성능-안티패턴-카탈로그.md)

## 6. 2판을 읽을 때 주의할 것 — 2024년 8월 이후 바뀐 것

2판은 JDK 21 기준이고 15장은 2024-08 시점이다. **JDK 25(2025-09) 에서 이미 달라진 것**은 [`01-최신-JDK-기준-평가.md`](01-최신-JDK-기준-평가.md) 에 명령과 출력으로 모아 뒀다. 요지 —

- 비세대형 ZGC 제거(24) → `-XX:-ZGenerational` 은 경고 후 무시 ✅
- Shenandoah 세대형 정식(25) ✅ · 컴팩트 객체 헤더 정식(25) ✅ · ScopedValue 정식(25) ✅ · AOT 캐시 정식(24·25) ✅
- 가상 스레드 `synchronized` 고정 해소(24) ✅
- SecurityManager 영구 비활성(24) ✅ · Unsafe 메모리 접근 경고(24~) ✅
- 구조적 동시성은 25 에도 미리보기, API 변경(`open()`) ✅ · Vector API 는 10번째 인큐베이터 📄 · Valhalla 미출시 📄
- 2판 12장이 아직 적은 `PrintGCApplicationStoppedTime` 은 17 부터 없다 ✅
- 2판 15장의 "21 에서 FFM 은 `jdk.incubator.foreign`" 은 부정확 — 21 은 `java.lang.foreign` 미리보기 ✅
